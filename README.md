# java-racingcar-precourse

구현 기능 목록

자동차 이름 입력 기능
-사용자로부터 경주할 자동차 이름을 입력받는다.
-이름은 쉼표(,)를 기준으로 구분하며, 각 이름은 공백이 없어야 한다.
-자동차 이름은 5자 이하만 가능하다.
-잘못된 입력(비어 있음, 5자 초과 등)은 IllegalArgumentException을 발생시킨다.
자동차 전진 조건 기능
-Randoms.pickNumberInRange(0, 9)로 무작위 숫자를 생성한다.
-무작위 값이 4 이상일 경우 자동차가 전진한다.
-3 이하일 경우 자동차는 정지한다.
라운드별 경주 실행 기능
-입력받은 횟수만큼 경주를 반복한다.
-각 라운드마다 모든 자동차가 이동 시도를 한다.
-각 라운드 결과를 즉시 출력한다.
우승자 판별 기능
-가장 많이 이동한 자동차를 우승자로 판별한다.
-여러 자동차가 동일한 거리를 이동했을 경우 공동 우승자로 처리한다.
-결과는 "최종 우승자 : pobi, jun" 형태로 출력한다.
예외 처리 기능
-자동차 이름이 비었거나 5자 초과일 경우 예외 발생
-이동 횟수가 잘못된 경우 예외 발생
-예외 발생 시 IllegalArgumentException만 던지고 출력은 하지 않는다.
