# java-racingcar-precourse

## 구현 기능 목록

### 자동차 이름 입력 기능
- 사용자로부터 경주할 자동차 이름을 입력받는다.
- 이름은 쉼표(,) 기준으로 구분된다.
- 이름은 5자 이하만 가능하다.
- 공백이 있거나 비어 있는 이름 입력 시 IllegalArgumentException을 발생시킨다.
### 자동차 전진 조건 기능
- Randoms.pickNumberInRange(0, 9)로 무작위 숫자를 생성하고 무작위 값이 4 이상이면 전진, 3 이하이면 정지한다.
- 전진 시 position이 1 증가한다.
### 라운드별 경주 실행 기능
- 사용자가 입력한 횟수만큼 모든 자동차의 이동을 반복 실행한다.
- 매 라운드마다 자동차들의 현재 이동 상태를 출력한다.
### 우승자 판별 기능
- 가장 많이 이동한 자동차를 우승자로 판별한다.
- 여러 자동차가 동일한 거리를 이동했을 경우 공동 우승자로 처리한다.
- 최종 결과는 "최종 우승자 : pobi, jun" 형태로 출력한다.
### 예외 처리 기능
- 잘못된 입력값(비어 있음, 5자 초과, 음수, 문자가 포함된 숫자 등) 입력 시 IllegalArgumentException을 발생시킨다.
- 예외 발생 시 별도의 에러 메시지를 출력하지 않고 프로그램을 종료한다.
